# 目标 05：环境与自定义上下文

> 状态：源码与自动化测试已实现（2026-10-29），依赖[目标 01](目标01-协议与安全边界.md)和[目标 03](目标03-事件与加密发送.md)，与目标 04 集成。真实浏览器、各浏览器网络信息准确性、真实接收端与数据留存仍未验证，详见[实现与验证记录](#实现与验证记录2026-10-29)。

## 目标与职责

SDK 为允许上报的错误事件附加有限的浏览器和网络环境信息，并调用接入方初始化时配置的回调读取当前业务上下文；服务端按协议接收并遵守既定数据访问及留存策略。

## 接口与行为约定

- 环境字段按实际 API 能力采集，首版只包含可获得的浏览器 UA、在线状态及网络有效类型（如 `4g`）；字段缺失时省略，不推断精确网络或设备身份。UA 可能包含识别信息，纳入隐私告知及服务端访问控制；不得收集 Cookie、请求头、请求体、完整 URL 或本地存储全部内容。
- 初始化可配置 `getContext` 回调，无参数，每次符合上报策略且准备处理事件时调用一次，返回普通 JSON 对象或其 Promise；登录和退出后的新状态可在后续事件体现。仅作为事件内的独立 `context` 字段，不合并到事件根字段，不允许覆盖事件、协议、CID 或安全字段。
- 上下文只接受可安全序列化的普通 JSON 数据：根值必须为普通对象；字符串、有限数字、布尔值、`null`、普通对象与数组以外的值（函数、Symbol、BigInt、`undefined`、`NaN`、`Infinity`、Date、Map 等）以及循环结构均视为无法安全归一化。任一项超限即丢弃整段上下文，不截断业务数据。
- 回调拒绝、抛错、返回非法值、包含循环结构或超过 1 秒未完成时，忽略本次自定义上下文，继续基础错误事件；捕获迟到 Promise 的拒绝，避免产生未处理异常。1 秒上限从调用回调前开始计时，但同步执行的部分运行在调用栈上、无法被中断，阻塞结束后才取得结果，此时合法结果仍会采用。同一初始化代次最多同时保留 5 个实际未结束的回调，超限时跳过回调并继续基础事件；超时不会取消应用的异步任务，未结束任务在当前代次内继续占名额，可能导致后续上下文缺失；并发额度按初始化代次独立计算，停止或重新初始化后重新开始，旧代次回调结束时只归还自己的额度。回调不会主动修改或扫描接入方存储，由应用自行读取和脱敏所需字段。
- 环境信息及上下文与错误事件共享目标 03 的明文和信封体积限制；明文超限时先移除 `context`，再移除 `environment`，最后缩短堆栈，基础事件仍超限才丢弃。路径、错误内容和自定义身份数据仍可能敏感，接入方须控制字段、授权与脱敏。

### 上下文限制

| 项 | 上限 |
| --- | --- |
| 整体 JSON | 4096 个 UTF-8 字节 |
| 容器嵌套深度 | 3，根对象算第 1 层 |
| 单个对象键数量 | 20 |
| 单个数组项数量 | 20 |
| 单个键 | 64 个 UTF-8 字节 |
| 单个字符串值 | 512 个 UTF-8 字节 |

### 环境采集来源

| 协议字段 | 浏览器来源 | 缺失或读取失败 |
| --- | --- | --- |
| `userAgent` | `navigator.userAgent` | 省略 |
| `online` | `navigator.onLine` | 省略 |
| `effectiveType` | `navigator.connection.effectiveType` | 省略，不推断 |

内部调用方显式传入的环境字段优先于自动采集值；两者都没有时明文不包含 `environment`。

## 实现与验证记录（2026-10-29）

- SDK 新增 `src/environment.ts:22`（`readEnvironment`）：逐个属性安全读取 `navigator`，属性缺失、空字符串或读取抛错时省略对应字段；在 `src/event.ts:184` 与显式传入值按字段合并。环境信息在等待上下文回调前读取（`src/event.ts:348`），避免反映回调等待期间的状态变化。安全读取函数与采集模块共用 `src/safe-read.ts`，避免两处读取规则分叉。
- SDK 新增 `src/context.ts`：`readContext`（`:126`）在事件通过允许状态与准备额度检查后调用一次回调，先建立超时再调用回调，随后最多等待 1 秒；`createContextSession`（`:39`）为每次激活的发送器创建独立额度，保证同一代次最多 5 个未结束回调，超时后回调真正结束前继续占用本代次名额，停止或重新初始化后重新计数。归一化复用事件准备阶段的 `TextEncoder`，不再按事件新建。同步抛错、Promise 拒绝、超时、非普通对象、循环结构、非 JSON 安全值、键/项/深度/字符串或整体体积超限都会返回 `undefined`，基础事件继续发送；迟到拒绝提前挂接处理，不产生未处理 Promise。
- `src/event.ts:255` 把归一化结果写入独立的 `context` 字段；`:269` 至 `:274` 在明文超限时先移除上下文，再按既有顺序移除环境并缩短堆栈。`src/index.ts:159` 向发送器传入读取当前初始化配置的访问器，重复初始化更新 `getContext` 后立即生效。

## 失败处理与验收

- 覆盖浏览器无网络信息 API、离线状态、权限或属性读取异常、上下文同步/异步成功、登录状态变化、回调超时/抛错/拒绝、循环对象、超大对象及保留字段冲突。确认基础事件仍能发送且不暴露无关存储数据。
- 由接入方与服务端确认采集字段、保留期限、访问范围和删除方式；真实用户数据、各浏览器的网络信息准确性及隐私合规流程尚未验证。
